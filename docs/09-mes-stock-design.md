# MES 库存归并实施设计

本次对应交付清单第 02 步，沿用已确认的 ERP 主档、WMS 实物库存、MES 生产事实归属。

1. `wms_inventory` 继续保存商品 SKU + 仓库的唯一总量和预占。新增 `wms_stock_position` 保存 MES 物料台账对应的库区、库位、批次分配量和预占；这些明细属于同一总量，不是第二份库存。
2. ERP 入库先产生未分配库存。MES 显式上架分配到指定库位及批次，分配只改变明细归属，不增加仓库实物总量。分配与现有库存桥接共用源意图、预占、提交/撤销和重试机制。
3. MES 台账只保存物料、位置和批次等元数据，查询数量从 WMS 明细读取。生产事务不再更新 MES 独立数量；WMS 同时校验仓库可用量和指定明细可用量，忽略“允许负库存”的旧入口。
4. MES 领料转入线边仓、退料转回实仓、生产消耗扣线边仓、产出入线边仓、成品入库转入实仓，均沿用原单据及流水并经 WMS 预占提交。线边仓也须显式映射到独立的 WMS 仓库。
5. ERP、商城及 WMS 原生出库先使用未分配量，不足部分按 WMS 明细 ID 顺序消耗未预占分配量，MES 查询立即反映结果。总量行先加锁，再处理明细，避免跨渠道并发超领；分配中的库存、其他业务的预占不能被消耗。
6. 原历史 MES 数量保留用于审计，不自动作为新库存导入。已有 WMS 实物通过显式分配关联生产批次，避免把原本已存在的商品重复入库。库位和批次选择继续校验，不能按相同数字 ID 推测商品或仓库映射。

验收从 ERP 入库开始，检查上架不增总量、领退料和生产流转、指定批次不足、并发抢同一批次、跨渠道出库反映到 MES、事务回滚和重复提交。未通过这些验证之前，第 02 步不标为完成。
